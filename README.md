# Учебная доска задач

Стартовый проект для модуля Redev AI agents. Это адаптивная React-доска с задачами в колонках «К выполнению», «В работе» и «Готово». Данные хранятся локально в браузере, поэтому с доской можно работать без сервера.

Поиск намеренно отсутствует: его вы добавите в ходе курса.

## Начало работы

Для работы нужны Node.js 22 и npm 10 или новее.

1. Нажмите **Use this template** на странице репозитория и создайте свой репозиторий.
2. Склонируйте созданный репозиторий и перейдите в его папку.
3. Установите зависимости:

   ```bash
   npm ci
   ```

4. Запустите приложение:

   ```bash
   npm run dev
   ```

Vite выведет в терминал локальный адрес, обычно `http://localhost:5173`.

## Команды

```bash
npm run dev       # запустить приложение в режиме разработки
npm test          # запустить тесты
npm run lint      # проверить код ESLint
npm run typecheck # проверить типы TypeScript
npm run check     # выполнить ESLint, проверку типов и тесты
npm run build     # собрать production-версию в dist/
```

Перед отправкой изменений выполните:

```bash
npm run check
npm run build
```

## Сброс демо-данных

В интерфейсе доски используйте действие «Сбросить данные» и подтвердите его. Оно вернёт исходные демонстрационные задачи.

Если приложение не открывается, удалите данные сайта для локального адреса в настройках браузера и перезагрузите страницу.

## Дорожная карта

Направления развития проекта — от ближайших шагов к долгосрочным.

1. **Поиск и фильтрация задач.** Поиск сейчас отсутствует намеренно: это самостоятельное задание, которое каждый участник курса выполняет на базе этого шаблона. Здесь появятся строка поиска по названию и описанию, а также фильтры по статусу, приоритету и сроку.

2. **Перетаскивание задач между колонками.** Сейчас задача перемещается кнопкой по фиксированному циклу «К выполнению» → «В работе» → «Готово» и снова по кругу. Добавим drag-and-drop, чтобы переносить карточку мышью сразу в нужную колонку.

3. **Сортировка и архив задач.** Задачи в колонках отображаются в порядке создания. Добавим сортировку по приоритету и сроку, а также архив для завершённых задач, чтобы колонка «Готово» не разрасталась.

4. **Серверное хранилище.** Данные хранятся в localStorage браузера. Интерфейс `TaskRepository` внедряется пропсом в `App`, поэтому замена localStorage-реализации на работу с бэкендом не затронет компоненты доски.

5. **Авторизация.** В проекте уже есть форма входа (`Login`), и параллельно добавляются роуты `/login` и `/register`. Свяжем их с серверным API и сделаем доску защищённой: работать с ней можно будет только после входа.

6. **Сквозные (e2e) тесты.** Логика и UI уже покрыты юнит- и интеграционными тестами на Vitest + Testing Library. Добавим e2e-сценарии основных потоков — создание, редактирование, перемещение и удаление задачи.

7. **Тёмная тема.** Сейчас оформление только светлое. Добавим переключатель светлой и тёмной тем на CSS-переменных с сохранением выбора пользователя.
