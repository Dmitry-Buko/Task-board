Добавь фичу «$0» в доску по конвенциям AGENTS.md:

1. Компонент. Если его нет — создай скиллом component в `src/features/tasks/components/`.
2. Подключение. Только через props от `TaskBoard`: UI не читает localStorage,
   данные идут через уже загруженный список задач.
3. Тесты. Обнови ассерты в `src/app/App.test.tsx` под новую разметку;
   русские строки сохраняй дословно, меняется способ запроса, не текст.
4. Прогон. `npm run check`, затем `npm run build` — обе стадии должны быть зелёными.

Перед началом прочитай `references/counter-example.md` — полный разбор
реального прогона (Counter: компонент → wiring → тесты → зелёный check).
Он нужен, если фича затрагивает статистику, `App.test.tsx` или ты делаешь
такую интеграцию впервые; на повторных простых случаях можно не перечитывать.
