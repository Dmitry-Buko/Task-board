## Вопросы к требованиям

Ничего блокирующего: текст сообщения и критерии готовности заданы точно.

Принятые по умолчанию решения (уточнить до реализации, если нужно иначе):

1. Мигание при загрузке: до разрешения `repository.load()` список задач пуст,
   поэтому сообщение на короткое время появится во всех трёх колонках.
   Критерии issue это не запрещают («в любой колонке, если в ней нет задач»),
   отдельное loading-состояние не вводится.
2. Сообщение видно всем пользователям (не только скринридерам), стили тихие,
   не конкурирующие с карточками задач.
